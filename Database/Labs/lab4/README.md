### Запрос №1 — RIGHT JOIN

Сделать запрос для получения атрибутов из указанных таблиц, применив фильтры по указанным условиям:

| Параметр | Значение |
|---|---|
| **Таблицы** | `Н_ЛЮДИ`, `Н_ВЕДОМОСТИ` |
| **Атрибуты** | `Н_ЛЮДИ.ОТЧЕСТВО`, `Н_ВЕДОМОСТИ.ЧЛВК_ИД` |
| **Соединение** | `RIGHT JOIN` |

Фильтры (AND):

- a) `Н_ЛЮДИ.ИД = 100865`
- b) `Н_ВЕДОМОСТИ.ЧЛВК_ИД < 117219`
- c) `Н_ВЕДОМОСТИ.ЧЛВК_ИД = 117219`

> ⚠️ **Логическое противоречие:** условия б) и в) несовместимы — `x < 117219 AND x = 117219` невозможно ни при каком целом `x`. PostgreSQL генерирует `One-Time Filter: false` и возвращает 0 строк без обращения к данным.

## Планы выполнения

### Запрос №1

| | План №1 | План №2 |
|---|---|---|
| **Метод** | Nested Loop Right Join | Hash Right Join |
| **Сложность** | O(N) при Index Scan | O(N + M) |
| **Оптимальный?** | ✅ Да | — |
| **Причина** | При `ИД = 100865` Nested Loop с Index Scan обходит Н_ВЕДОМОСТИ ровно один раз | Hash строится избыточно для единственной строки |

*Оба плана возвращают 0 строк из-за логического противоречия в условиях фильтрации.*

### Запрос №2

| | План №1 | План №2 |
|---|---|---|
| **Метод** | Nested Loop Join | Hash Join |
| **Сложность** | O(N · M · K) | O(N + M + K) |
| **Оптимальный?** | — | ✅ Да |
| **Причина** | Полный перебор неприемлем для больших таблиц | Линейная сложность, σ применяется до ⋈ |

## Индексы

### Запрос №1

```sql
CREATE INDEX "ИНД_ЛЮД_ИД"
    ON "Н_ЛЮДИ" USING HASH ("ИД");

CREATE INDEX "ИНД_ВЕД_ЧЛВК"
    ON "Н_ВЕДОМОСТИ" USING BTREE ("ЧЛВК_ИД");
```

| Индекс | Тип | Обоснование |
|---|---|---|
| `Н_ЛЮДИ.ИД` | `HASH` | Поиск по равенству `ИД = 100865` за O(1) |
| `Н_ВЕДОМОСТИ.ЧЛВК_ИД` | `BTREE` | Поддерживает равенство и диапазонное сравнение (`<`) за O(log n) |

### Запрос №2

```sql
CREATE INDEX "ИНД_ЛЮД_ИМЯ"
    ON "Н_ЛЮДИ" USING BTREE ("ИМЯ");

CREATE INDEX "ИНД_ВЕД_ИД"
    ON "Н_ВЕДОМОСТИ" USING BTREE ("ИД");

CREATE INDEX "ИНД_ВЕД_ЧЛВК"
    ON "Н_ВЕДОМОСТИ" USING HASH ("ЧЛВК_ИД");
```

| Индекс | Тип | Обоснование |
|---|---|---|
| `Н_ЛЮДИ.ИМЯ` | `BTREE` | Диапазонный запрос `ИМЯ < 'Роман'` за O(log n + k) |
| `Н_ВЕДОМОСТИ.ИД` | `BTREE` | Диапазонный запрос `ИД < 1426978` за O(log n + k) |
| `Н_ВЕДОМОСТИ.ЧЛВК_ИД` | `HASH` | Соединение по равенству за O(1) |
