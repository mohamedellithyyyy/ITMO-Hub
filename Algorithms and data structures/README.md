# Algorithms and Data Structures - Timus Problems

This repository contains solutions and reports for selected Timus Online Judge problems.

Each directory contains:
- `solution.cpp` → C++ solution code
- `report.tex` → LaTeX report
- `explanation.docx` → Step-by-step solution explanation
- `README.md` → This file (problem info and link)
