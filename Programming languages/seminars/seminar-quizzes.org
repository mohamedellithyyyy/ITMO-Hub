* Как это использовать

  По 5 вопросов на каждый из 8 семинаров — короткая проверка теории (5-7 минут) в конце занятия, после того как практическая часть сдана преподавателю практики. Формат — Google Forms:

  1. Создать один Google Form на семинар (или один общий form с секциями — Section per семинар, если хотите единую ссылку на весь курс)
  2. Тип вопроса "Multiple choice" для вопросов с вариантами, "Short answer" — где явно указано
  3. Включить настройку формы "Quiz mode" (Settings → Make this a quiz), проставить баллы и правильные ответы — на любой Google-аккаунт можно сделать это за несколько минут
  4. Правильный ответ помечен *звёздочкой* в списке вариантов ниже
  5. Раздать студентам ссылку/QR-код в конце занятия; результаты доступны сразу в Google Forms → Responses

  Автотесты на код (сборка/компиляция семинарских примеров) настроены отдельно, см. =.gitlab-ci.yml= в корне репозитория — эти два механизма дополняют друг друга: CI проверяет практику, квиз — теорию.

* Семинар 1. Среда выполнения, основы языка ассемблера

  1. (Multiple choice) Какой регистр хранит адрес следующей исполняемой инструкции?
     - rsp
     - *rip*
     - rbp
     - rflags

  2. (Multiple choice) Какой поток вывода по умолчанию используется для сообщений об ошибках?
     - stdin
     - stdout
     - *stderr*
     - stddebug

  3. (Short answer) Какой системный вызов (номер или имя) используется, чтобы завершить процесс в примере =hello.asm=?
     Ответ: exit (номер 60)

  4. (Multiple choice) В какой секции ассемблерной программы располагаются статические данные, такие как строка сообщения?
     - .text
     - *.data*
     - .bss
     - .rodata

  5. (Short answer) Как называется команда gdb, которая выполняет ровно одну машинную инструкцию?
     Ответ: stepi (si)

* Семинар 2. Вызов функций, использование стека, конечные автоматы

  1. (Multiple choice) В какую сторону растёт стек на x86-64 при выполнении =push=?
     - В сторону увеличения адресов
     - *В сторону уменьшения адресов*
     - Зависит от компилятора
     - Не растёт, фиксированный размер

  2. (Multiple choice) Что из перечисленного НЕ является частью соглашения о вызовах (calling convention)?
     - Порядок передачи аргументов через регистры
     - Кто сохраняет caller-saved регистры
     - Выравнивание стека перед call
     - *Название функции в исходном коде*

  3. (Short answer) Как называется автомат, в котором из одного состояния по одному символу возможен ровно один переход?
     Ответ: детерминированный конечный автомат (ДКА)

  4. (Multiple choice) Что произойдёт, если не восстановить стек после вызова функции (не сбалансировать push/pop)?
     - Ничего, компилятор сам исправит
     - *Программа обратится не по тому адресу при следующем ret*
     - Увеличится производительность
     - Изменится точка входа

  5. (Short answer) Какая теорема утверждает эквивалентность выразительной силы регулярных выражений и конечных автоматов?
     Ответ: теорема Клини

* Семинар 3. Цикл компиляции, препроцессор, утилита make

  1. (Multiple choice) Расположите по порядку: ассемблирование, препроцессинг, компоновка. Что идёт первым?
     - Ассемблирование
     - *Препроцессинг*
     - Компоновка

  2. (Multiple choice) Что хранит таблица релокаций?
     - Список всех переменных программы
     - *Информацию для исправления адресов при компоновке объектных файлов*
     - Список ошибок компиляции
     - Историю изменений файла

  3. (Short answer) Какая директива препроцессора C используется для включения содержимого другого файла?
     Ответ: #include

  4. (Multiple choice) В Makefile что определяет, нужно ли пересобирать цель?
     - Размер файла
     - *Время модификации файла-зависимости относительно цели*
     - Порядок целей в файле
     - Число строк в файле

  5. (Short answer) Как называется специальный символ в правиле make, который подставляет имя первой зависимости?
     Ответ: $<

* Семинар 4. Виртуальная память, загрузка программ

  1. (Multiple choice) Какой инструмент/файл в Linux показывает карту памяти работающего процесса?
     - =/proc/PID/status=
     - *=/proc/PID/maps=*
     - =/proc/PID/mem=
     - =/proc/PID/cmdline=

  2. (Multiple choice) Что делает системный вызов =mmap= с флагом =MAP_ANONYMOUS=?
     - Отображает файл в память
     - *Выделяет область памяти, не связанную ни с каким файлом*
     - Удаляет отображение из памяти
     - Копирует память другого процесса

  3. (Short answer) Как называется заголовок ELF-файла, описывающий сегменты, которые загрузчик должен отобразить в память?
     Ответ: program header (программный заголовок)

  4. (Multiple choice) Зачем нужны динамические библиотеки?
     - Чтобы код работал быстрее
     - *Чтобы не дублировать один и тот же код в каждом исполняемом файле и экономить память*
     - Чтобы скрыть исходный код
     - Это требование стандарта C

  5. (Short answer) Какая структура данных отвечает за преобразование виртуального адреса в физический?
     Ответ: таблица страниц (page table)

* Семинар 5. Аспекты языка C, препроцессор языка C, _Generic

  1. (Multiple choice) Что из перечисленного относится к семантике языка, а не к синтаксису?
     - Правильность расстановки скобок
     - *Смысл выражения =a + b= в зависимости от типов a и b*
     - Ключевые слова языка
     - Порядок токенов в выражении

  2. (Multiple choice) На каком этапе происходит выбор ветки в конструкции =_Generic=?
     - Во время выполнения программы
     - *Во время компиляции, по статическому типу выражения*
     - Определяется операционной системой
     - Случайным образом

  3. (Short answer) Как называется свойство макроса препроцессора C, при котором он принимает переменное число аргументов (=...=)?
     Ответ: вариативный макрос (variadic macro)

  4. (Multiple choice) Что делает условный макрос =#ifdef DEBUG=?
     - Всегда включает код
     - *Включает следующий код только если макрос DEBUG определён*
     - Определяет макрос DEBUG
     - Выводит ошибку компиляции

  5. (Short answer) Какой оператор препроцессора превращает аргумент макроса в строковый литерал?
     Ответ: # (stringizing operator)

* Семинар 6. Аллокация памяти, архитектура

  1. (Multiple choice) Что такое внешняя фрагментация памяти?
     - Повреждение данных в куче
     - *Суммарно свободной памяти достаточно, но она разбита на маленькие несмежные блоки*
     - Утечка памяти
     - Переполнение стека

  2. (Multiple choice) Что произойдёт при обращении к памяти после её освобождения (use-after-free)?
     - Гарантированно программа завершится с ошибкой сегментации
     - *Неопределённое поведение — от отсутствия видимых проблем до порчи данных*
     - Память автоматически восстановится
     - Компилятор не даст скомпилировать такой код

  3. (Short answer) Как называется стратегия аллокатора, которая ищет первый подходящий по размеру свободный блок?
     Ответ: first-fit

  4. (Multiple choice) Что такое непрозрачный (opaque) тип данных?
     - Тип, который нельзя использовать в C
     - *Тип, чьё внутреннее представление скрыто за интерфейсом*
     - Тип без имени
     - Синоним для void*

  5. (Short answer) Как называется дерево, представляющее структуру выражения после синтаксического анализа, без незначащих деталей грамматики?
     Ответ: AST (абстрактное синтаксическое дерево)

* Семинар 7. Оптимизации, уязвимость стека

  1. (Multiple choice) Что делает пролог функции?
     - Восстанавливает регистры перед возвратом
     - *Сохраняет базовый указатель и выделяет место под локальные переменные*
     - Освобождает память кучи
     - Вызывает следующую функцию

  2. (Multiple choice) Что такое хвостовая рекурсия?
     - Рекурсия с более чем одним рекурсивным вызовом
     - *Рекурсивный вызов, являющийся последним действием функции, что позволяет заменить его циклом*
     - Рекурсия без базового случая
     - Любой вызов функции самой себя

  3. (Short answer) Какой спецификатор printf позволяет прочитать/записать память через уязвимость форматной строки?
     Ответ: %n

  4. (Multiple choice) Что перезаписывается при классической атаке переполнения буфера на стеке?
     - Заголовок ELF-файла
     - *Сохранённый адрес возврата в кадре стека*
     - Код операционной системы
     - Таблица символов

  5. (Short answer) Какое ключевое слово C запрещает компилятору оптимизировать обращения к переменной, считая, что она может измениться "извне"?
     Ответ: volatile

* Семинар 8. Процессы, потоки, модели памяти

  1. (Multiple choice) Что наследует дочерний процесс при вызове =fork=?
     - Ничего, начинает с чистого состояния
     - *Копию адресного пространства родителя на момент вызова*
     - Только открытые файлы
     - Только переменные окружения

  2. (Multiple choice) Чем поток принципиально отличается от процесса?
     - Поток не может выполнять код
     - *Потоки в рамках одного процесса разделяют общее адресное пространство*
     - У потока не может быть своего стека
     - Процессы всегда быстрее потоков

  3. (Short answer) Как называется ситуация, когда два потока одновременно обращаются к общей памяти, и хотя бы одно обращение — запись, без синхронизации?
     Ответ: гонка данных (data race)

  4. (Multiple choice) Для чего нужен барьер памяти (memory barrier)?
     - Ускорить выполнение программы
     - *Гарантировать видимый другим потокам порядок операций с памятью*
     - Освободить память
     - Остановить все потоки навсегда

  5. (Short answer) Чем принципиально отличается семафор от мьютекса?
     Ответ: семафор — счётный примитив, допускает больше одного "владельца" одновременно (обобщение мьютекса)
